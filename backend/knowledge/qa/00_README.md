# QA knowledge corpus

Este directorio contiene mappings locales de lineamientos QA usados por el análisis. Cada guideline es una unidad recuperable y conserva su `guidelineId` en el texto y en metadata.

Las referencias a ISO/IEC 25010:2023, ISO/IEC/IEEE 29119, NIST SP 800-218 SSDF, OWASP ASVS y OWASP WSTG identifican la fuente del mapping; este producto no emite certificaciones ni sustituye una auditoría profesional.

Formato: cada bloque `## QA-* — título` incluye `Domain`, `Source`, `Source version`, `Priority` y `Tags`.
